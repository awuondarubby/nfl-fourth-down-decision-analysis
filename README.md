# NFL Fourth Down Decision Analysis

## Project Overview

This project analyzes NFL fourth down decision-making behavior using 2025 play-by-play data and logistic regression modeling in SAS. The objective was to identify the factors that influence whether teams choose to go for it on fourth down or select a kick decision.

## Tools and Technologies

* SAS
* Logistic Regression
* Statistical Modeling
* Sports Analytics
* Data Analysis

## Key Variables Analyzed

* Yards to go
* Field position
* Score differential
* Game quarter
* Time remaining
* Team timeouts

## Project Files

* `nfl_fourth_down_analysis_code.sas` – SAS analysis code
* `nfl_fourth_down_analysis_report.docx` – Final project report
* `nfl_analysis_results.pdf` – Statistical output and analysis results

## Key Insights

The analysis showed that shorter yardage situations strongly increased the likelihood of teams attempting fourth down conversions. Logistic regression modeling demonstrated strong predictive performance in identifying fourth down decision behavior.

## Dataset

The project used 2025 NFL play-by-play data for selected NFL teams.
